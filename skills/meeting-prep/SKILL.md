---
name: meeting-prep
description: Prepare for a meeting or call, with an agenda, questions to ask, and notes from files the user points to.
---
1. Ask only for what is missing: who it is with, what it is about, how long it is.
2. If the user names a file or folder with background material, read it with read_file and pull out what is relevant.
3. Produce: a 3-5 item agenda with time boxes, 3 questions worth asking, and 2 risks or open points.
4. Offer to save the result with write_file (confirm the file name first). Do not send it to anyone.
